# Open-source research

Reviewed on 2026-09-22. The implementation in this repository is original;
the projects below were used as architectural references rather than copied as
source modules or assets.

## upstream-ray/codex-usage-monitor

- License: MIT, copyright Craig Constable (2025).
- Studied: Windows tray/menu behavior, per-user HKCU startup, quota alert
  de-duplication, local-time reset display, multi-monitor taskbar handling.
- Decision: did not reuse its direct credential/HTTP polling path. Codex Usage
  Pet uses the official local App Server instead.

## Corread8/codex-usage-monitor

- License: MIT, copyright Correa (2026).
- Studied: lightweight persistent `codex app-server` subprocess, rate-limit
  bucket selection, timeout and process cleanup, 5h/weekly normalization.
- Decision: implemented a separate concurrent JSON-RPC client that also sends
  the current documented `initialized` notification and listens for updates.

## JDMarston/codex-usage-widget

- License: MIT, copyright JDMarston (2026).
- Studied: tray-oriented Windows widget UX, always-on-top toggle, countdowns,
  one-directory PyInstaller packaging, refresh cadence while hidden.
- Decision: retained a 60-second default because it is explicitly required for
  fallback polling, but App Server update events can trigger earlier refreshes.

## tong666-bit/DaJuZi

- License: MIT, copyright DaJuZi contributors (2026).
- Studied: transparent frameless Qt tool window, drag handling across screens,
  position clamping, low-frequency animation, HKCU startup, PyInstaller onedir.
- Decision: selected PySide6 Essentials instead of PyQt5, and created an
  original QPainter pet so no third-party sprite assets are distributed.

## Official source

The protocol contract was verified against the official Codex App Server
documentation and JSON Schema generated by the locally installed Codex CLI.
The generated schema was used for development only and is not vendored.
