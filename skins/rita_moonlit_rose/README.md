# Rita · Moonlit Rose

This built-in Skin Pack demonstrates a complete theme-only variant: the panel,
progress bars, hover color, warnings, borders, menu, and decorator are supplied
by its own `skin.json`.

It intentionally carries an independent copy of the same original
project-created Rita-inspired sprite sheet as the default pack. It does not add
or redistribute third-party artwork.

The interaction timing is declared in `skin.json` through optional
`frame_durations_ms`. The runtime `stretch` slot uses the restrained
`animations/tidy_hair.png`, and LOW enters its final seated pose through
`animations/sit_transition.png`. QA contact sheets and motion previews are
under `artifacts/animations/rita_moonlit_rose/`.
